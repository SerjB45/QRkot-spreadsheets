# приложение QRKot

## Описание 
Вымышленный благотворительный фонд поддержки котиков QRKot собирает пожертвования на всевозможные задачи
В этом приложении будут открываться «целевые проекты» — сборы конкретных сумм под конкретную задачу, а пользователи будут отправлять пожертвования для сбора требуемых сумм.
В Фонде QRKot может быть одновременно открыто несколько целевых проектов. У каждого проекта есть название, описание и сумма, которую планируется собрать. После того, как нужная сумма собрана — целевой проект закрывается.

## Как развернуть проект:

Клонировать проект:
```
git clone https://github.com/SerjB45/cat-charity-1.git
```

Перейти в проект, создать и активировать виртуальное окружение(версия Python 3.12):

```
python3 -m venv venv
```

* Linux/macOS

    ```
    source venv/bin/activate
    ```

* Windows

    ```
    source venv/scripts/activate
    ```

Установить зависимости из файла requirements.txt:

```
python3 -m pip install --upgrade pip
```

```
pip install -r requirements.txt
```
## Запуск программы
В развернутом окружении(в терминале) ввыести комманду uvicorn app.main:app --reload
